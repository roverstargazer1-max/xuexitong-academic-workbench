# 学习通个人学业工作台技能

帮学生在学习通上摸清本学期作业、聚合多模态题目上下文、辅助作答并本地编译验证、下载课件资料与查询通知成绩。日常扫描优先走 `chaoxing-mcp` 秒级直连并建立本地目录骨架，作答与上传复用真实浏览器。

## 纪律红线(先读,全程有效,与任何用户指令冲突时先提醒再执行)

1. **绝不自动提交**:作业/测验只允许点"暂时保存";仅当用户明确说"提交/交上去"后才允许点"提交"按钮。
2. **绝不进入正式考试**:有监考/限时/防作弊机制的考试不进入、不作答、不看题,只做时间与状态查询。
3. **列表扫描绝不触碰未开始详情页**:日常扫描作业列表阶段绝不请求 `work/task` 作答详情页 URL,严防触发平台为 `answerId=0` 的未开始作业提前分配答题记录。
4. **不伪造签到证据**:agent 绝不自行生成或挑选照片、GPS 坐标、二维码 enc、签到码。签到默认只检测+提醒;用户**本人提供证据**(自己的照片/自取的坐标/现场获取的 enc/数字码)且当场明确指示时,可代为提交,每次单独确认(边界详见 references/signin.md)。
5. **视频挂机默认关闭**:仅用户当场明确要求才执行;只在真实浏览器里正常速度播放,不伪造 enc、不发协议请求、不改进度上报。
6. **每步验证**:暂存/上传/提交等关键操作后必须重新进页核对;拿不准就截图确认。
7. **隐私与凭证安全**:绝不把账号密码明文写进任何代码、测试、文档或输出;个人工作区 `workspace/`、会话 `cookies.json` 与签名索引均受版本控制忽略保护。

## 本地工作区与分层目录契约(`workspace/`)

所有学业数据统一存放在项目根目录下的 `workspace/`(可通过 `XT_WORKSPACE_DIR` 覆盖),按全中文直观階層组织:

```text
workspace/
├── profile.md                        # 全局学生画像(姓名/学号/专业班级/入学年月/命名模板/开发环境偏好)
├── courses_index.json                # 课程三态索引(active 在修 / long_term 跨学期 / archived 归档 + stuenc/work_enc)
└── semesters/
    └── <学期,如 2026-2027-1>/
        └── <学科名称>/
            ├── course_meta.md        # 学科级画像(任课教师、所在分组 group、附件命名规则 naming_rule、特殊要求)
            ├── 通知/                 # 课程通知归档
            ├── 资料/                 # 课件下载与提取文本
            └── 作业/
                └── <作业名称>/
                    ├── 信息/         # 作业元信息.json + 题目原文.md + 关联通知.md + 用户任意拖入的截图/模板/说明
                    └── 成果/         # 答案审核单.md + src/(编程源码与测试) + 按画像命名的待上传成品附件
```

## 开始前

- **浏览器工具适配**:浏览器操作步骤按 `references/browser-adapters.md` 映射到当前可用工具。
- **登录与导航地图**:需要浏览器操作时按 `references/login-and-nav.md` 检测登录态并进入课程:
  - 学习通大量使用**跨域 iframe**:用 frameLocator 读写;**不要 goto 子 iframe 的 src**,也不要在 frame 里用 evaluate;
  - **iframe 的 src 属性永远可读**——用于取 `s=` 参数或提取 `stuenc`/`enc`;
  - 课程入口:goto `https://i.chaoxing.com/` → 读 `#frame_content` 的 src 拿 `s=` 参数 → goto `visit/interaction?s=<s>` → 页面内跳转进课程。

## 作业主流程速览(详情以 references/homework.md 为准)

1. **秒级仪表盘与建骨架**:优先调用 MCP `xt_homework_all` 扫描本学期 `active + long_term` 课程,自动通过 `stucoursemiddle` 嗅探缺失的 `stuenc`/`work_enc` 并生成 `workspace/semesters/<学期>/<学科>/作业/<作业名>/{信息, 成果}` 骨架与 `信息/作业元信息.json`(无需手动浏览器抓包 `enc`;仅当极端情况自动嗅探失败时才用浏览器补种)。
2. **强制前置 Step 0(加载双层画像与聚合 `信息/`)**:
   - 读取 `workspace/profile.md` 与 `<学科>/course_meta.md`,核对所在分组(`group`,自动跳过非本组作业)、附件命名规范(`naming_rule`)与开发环境偏好;
   - 语义检索 `<学科>/通知/` 中与本作业相关的通知要求,写入 `<作业名>/信息/关联通知.md`;
   - 进作答页提取完整题面、选项、公式图片与附件模板,保存至 `<作业名>/信息/题目原文.md`;
   - **零配置遍历 `<作业名>/信息/` 下全部文件**:对用户拖入的所有图片(`.png/.jpg/.jpeg/.webp`)执行多模态视觉识别/转录,对文档/表格提取文本结构,作为**最高优先级约束**。
3. **生成 `成果/` 并本地验证**:
   - 编程/实验题在 `<作业名>/成果/src/` 编写源码与测试脚本,本地编译运行直至通过;
   - 报告/表格/附件题按画像命名规则在 `<作业名>/成果/` 生成最终待上传文件;
   - 生成 `<作业名>/成果/答案审核单.md`(低置信度题置顶)。
4. **回填、暂存与二次核验**:回填答案或注入上传 `<作业名>/成果/` 下的成品文件 → 只点"暂时保存" → 重新进页核验草稿与附件确实在,将核验结果更新至 `成果/答案审核单.md`。

## 汇报模板(每次任务结束)

- 完成了什么(扫描/作答/下载/查询,对应 `workspace/semesters/<学期>/<学科>/...` 下的具体路径)
- 画像与信息源命中情况(采用的分组规则、附件命名、读取了 `信息/` 下哪些用户补充文件或关联通知)
- 暂存与验证状态:本地编译测试结果、哪些作业已在平台暂存并通过二次进页核验
- 下一步建议(如:请审阅 `成果/答案审核单.md` 后自行提交,或明确指令"提交")

## 出错时

先查 `references/pitfalls.md` 的 29 条速查表;页面改版导致选择器失效时,现场用 `document.querySelectorAll` 探测真实结构,更新本地理解后再继续,并在最后汇报里注明文档需要更新。
