# 通知 / 成绩 / 进度 / 考试(只读查询与通知本地归档)

本模块除将课程通知归档至本地 `workspace/semesters/<学期>/<学科>/通知/` 外,其余对学习通平台全部**只读**:只查看、汇总、汇报,不改动任何平台数据。考试相关严格遵守红线第 2 条。

## 通知(含归档至 `<学科>/通知/` 与作业语义关联)

- **个人通知**:goto `https://i.chaoxing.com/mooc-ans/mooc2/notifycourse?...`(或空间页左侧"通知"入口),通知在子 iframe 里就按导航技巧读取。
- **课程内通知**:课程页"更多"→"通知"(部分课程在顶部直接有"通知"标签)。
- **本地归档契约**:
  1. 提取到的课程通知按时间倒序整理为 `{发布时间, 来源课程, 标题, 正文全文, 附件说明}`,同步写入 `workspace/semesters/<学期>/<学科>/通知/课程通知汇总.md`(重要长通知也可单独存为 `<学科>/通知/<日期>_<安全标题>.md`)。
  2. 当准备作答某项作业时(见 `references/homework.md` Step 0.2),Agent 读取 `<学科>/通知/` 下的通知内容,通过**正文语义关联**(例如通知标题叫"关于实验一提交格式的补充说明",对应作业列表中的"上机实验1-简易向量")摘录与该作业相关的格式要求、分组名单或截止变更,生成 `<学科>/作业/<作业名>/信息/关联通知.md`。

## 成绩

- 课程页"统计"或"成绩"标签(名字随教师设置而定,常见"统计"),子 iframe 读取或 goto 成主文档。
- 读取作业/章节测验/考试的得分列表(表头 + 行数据;拿不到就截图视觉转录)。
- 输出 markdown:`项目 | 得分 | 满分 | 状态`;只汇总,不尝试改动或"重做"。

## 章节进度(只读)

- 课程页"章节"标签 → 章节目录树,每小节有任务点完成状态(绿点/橙色待办/百分比)。
- 汇总:总进度、未完成小节清单(标注类型:视频/测验/讨论)。
- **只查看与汇报**。刷视频属灰色功能,见 `tasks.md` 且默认关闭——不要在这里顺手代刷。

## 考试安排

- 课程页"考试"标签 → 列表含考试名、开始/结束时间、状态(未开始/进行中/已结束)。
- 输出时间表,**只做查询**。
- **红线**:绝不进入进行中的考试作答页、不查看考试题目、不碰"开始考试"按钮。
